# Notes on interpreting the dataset

- The csv dataset contains the following:
    - Solvent Combinations [DCB, CB, TOL]
    - Annealing Temperature [in °C]
    - Sheet Resistance [in Ω]

- The Sheet Resistance value is not the true value, we have scaled it for privacy reasons before the actual publication of this particular study.

- The FAIR dataset is named ```FAIR_sheet_resistance.json```.
