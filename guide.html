React Forms Customization Guide for AI-Assisted Development

Form Overview

  • Form 1: NewProduct.dialog.js – A dialog form for creating new product experiments with basic input fields.
  • Form 2: Form.dialog.js – A comprehensive update form with file uploads, dynamic arrays, and tabbed interface for editing existing product data.

General Architecture Pattern

Both forms follow this structure:
  • State Management: React hooks for form data, dialog visibility, and file handling
  • Data Source: MongoDB Atlas functions via user context
  • UI Framework: PrimeReact components
  • File Handling: Custom upload components with DigitalOcean storage
  • Validation: Form submission validation with toast notifications

Customization Guide for Form.dialog.js

4. Adding Dynamic Array Fields

Objective: Add new measurement types that can have multiple entries.
AI Prompt Example:
"Add a new dynamic array field called 'resistance' to the Form.dialog.js. It should have the same structure as other measurement fields (batch, reading, who) and include add/remove functionality. Place it in a new tab called 'Resistance Measurements'."
Steps:
1. Update emptyProduct structure (around line 20): 
"resistance": [{
  "batch": "Please enter batch number",
  "reading": "Please enter reading",
  "who": "Please enter your group name"
}]
2. Create handler functions: 
const handleResistanceChange = (e, index, field) => {
  const newResistance = [...formData.resistance];
  if(field === 'batch'){
    newResistance[index].batch = e.target.value;
  }
  if(field === 'reading'){
    newResistance[index].reading = e.target.value;
  }
  if(field === 'who'){
    newResistance[index].who = e.target.value;
  }
  setFormData({ ...formData, resistance: newResistance });
};

const addResistance = () => {
  setFormData({
    ...formData,
    resistance: [...formData.resistance, { batch: '', reading: '', who: '' }],
  });
};
3. Add to JSX within TabView: 
<TabPanel header="Resistance Measurements">
  {formData?.resistance.map((singleResistance, idx) => (
    <div key={idx}>
      <label>Batch ID</label>
      <InputTextarea 
        value={singleResistance.batch} 
        onChange={(e) => handleResistanceChange(e, idx, 'batch')} 
        rows={1} 
        cols={30}
      />
      <label>Reading</label>
      <InputTextarea 
        value={singleResistance.reading} 
        onChange={(e) => handleResistanceChange(e, idx, 'reading')} 
        rows={1} 
        cols={30}
      />
      <label>Entry Person</label>
      <InputTextarea 
        value={singleResistance.who} 
        onChange={(e) => handleResistanceChange(e, idx, 'who')} 
        rows={1} 
        cols={30}
      />
    </div>
  ))}
  <Button label="Add Resistance Measurement" onClick={addResistance} />
  <Button label="Save" onClick={() => saveProduct(allTypes[0])} />
</TabPanel>

Common Patterns to Reference

Data Flow Pattern:

  1. State Management: formData → handler functions → setFormData
  2. File Upload: UploadComponent → functionToSetFiles → uploadFile → saveProduct
  3. Validation: Submit validation → toast notifications → MongoDB update

Component Structure:

Dialog
├── TabView
│   ├── TabPanel (Metadata)
│   ├── TabPanel (Measurements with dynamic arrays)
│   └── TabPanel (File uploads)
├── Toast (notifications)
└── Footer (action buttons)

This guide provides a foundation for AI-assisted customization of both React forms. Each modification should follow the established patterns for consistency and maintainability.
